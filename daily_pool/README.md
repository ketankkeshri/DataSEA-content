# Daily Pool — track-scoped MCQ schedule

Pre-generated, date-stamped MCQs that power **Daily 5** (and, optionally, quiz
packs / daily challenge fallbacks) for the DataSEA app — without ever needing
a content push.

## Layout

```
daily_pool/
  _index.json                  # global metadata: tracks, date ranges, month list
  data-analyst/<YYYY-MM>.json  # one file per (track, month)
  data-engineer/<YYYY-MM>.json
  data-science-ml/<YYYY-MM>.json
  dataops-mlops/<YYYY-MM>.json
```

## Question schema

```json
{
  "id": "de-04139",
  "category": "Spark",
  "difficulty": "easy",
  "question": "...",
  "options": ["A","B","C","D"],
  "correctIndex": 1,
  "xp": 10,
  "coins": 2,
  "availableFrom": "2026-06-10",
  "bucket": "daily-5"
}
```

* `id` — globally unique, track prefix (`da`/`de`/`ds`/`mo`) + 5-digit number.
* `availableFrom` — `YYYY-MM-DD`. **The app must filter `availableFrom <= today`
  on every read.** Questions for future dates ship with the bundle but stay
  invisible.
* `bucket` — currently always `"daily-5"`. Reserved for future per-feature splits
  (e.g. `"daily-challenge"`, `"pool"`).

## Allocation

Generated by `scripts/generate_daily_pool.py` with these defaults:

| Track            | Questions | Daily-5/day | Coverage |
|------------------|-----------|-------------|----------|
| data-analyst     | 10,000    | 5           | ~5.5 years (to 2031-11-30) |
| data-engineer    | 5,000     | 5           | ~2.7 years (to 2029-03-05) |
| data-science-ml  | 5,000     | 5           | ~2.7 years (to 2029-03-05) |
| dataops-mlops    | 5,000     | 5           | ~2.7 years (to 2029-03-05) |

Start date is set in the script (`START_DATE = 2026-06-10`).

## Regenerate

```bash
# source files must be at ~/Downloads/DataSEA/MCQS/
python3 scripts/generate_daily_pool.py
```

The script is idempotent (wipes the per-track folder before writing). Seed is
fixed (`42`) so identical input → identical output.

## App-side contract (TODO)

The app should:

1. On launch (or weekly), fetch `_index.json` and the next ~3 months of the
   user's selected track from `daily_pool/<selected-track>/<YYYY-MM>.json`.
2. Store all downloaded questions in a Room table keyed by `id` with the
   `availableFrom` column indexed.
3. Daily-5 picker: `SELECT * WHERE track = :selected AND availableFrom = :today
   AND bucket = 'daily-5' ORDER BY id LIMIT 5`. Deterministic → same 5 every
   time the user opens it on a given day.
4. **All MCQ-driven features (Daily 5, future MCQ-style daily challenges, quiz
   packs that draw from the pool) must filter by the user's selected track.**
   Module lessons stay open across tracks.
